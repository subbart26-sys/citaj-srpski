# Čitaj srpski

Версия v24.

В тренировке «Русское предложение → собрать сербское» пользователь видит только русский перевод предложения и набор перемешанных сербских слов. Название исходного текста, номер предложения и служебная информация об источнике не показываются.

Сербское предложение берётся целиком из существующих текстов библиотеки сайта; новые предложения не генерируются.
