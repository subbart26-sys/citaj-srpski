# Čitaj srpski — v27

Версия для тестирования.

Что изменено в v27:
- убрана старая отдельная база из 20 искусственно подготовленных предложений; тренировка собирает целые предложения непосредственно из текстов сайта;
- после занятия показывается итог: всего заданий, правильные, ошибки, подсказки, пропуски и процент;
- «Показать правильный» теперь учитывается отдельно как «с подсказкой», а «Пропустить» — отдельно; успешный проход по-прежнему засчитывается только при самостоятельной правильной сборке;
- сохранена система 3 успешных проходов с интервалами;
- исправлен баг в тренировке «слово → перевод», из-за которого при правильном ответе коробка могла продвинуться сразу на два шага;
- вся озвучка текста теперь явно использует установленный сербский голос, а не голос браузера по умолчанию;
- уточнены несколько переводов импортированного словаря, в том числе muzlica и muža;
- личные слова и прогресс сохраняются в localStorage и не очищаются обновлением версии.

Важно: браузерная озвучка может правильно выбрать сербский язык, но не гарантирует словарное лексическое ударение. Для следующего этапа качественной озвучки нужен отдельный сербский TTS с поддержкой SSML/фонетических подсказок и словарь ударений.
