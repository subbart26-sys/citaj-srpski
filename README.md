# Čitaj srpski — v4

Версия 4: каждое слово в тексте кликабельно, включая короткие служебные слова. Неизвестное слово тоже можно сохранить в «Мои слова» с пометкой «Перевод пока не добавлен».

Добавлены 4 больших учебных адаптации A1/A2 по мотивам общеизвестных народных сказок и сербских народных приповедок. Это не копии современных переводов.

Источники сюжетов для дальнейшей проверки: Serbian folk tales on Serbian Wikisource, including collections associated with Vuk Karadžić. Original historical texts are public domain; Wikisource pages also state their reuse licensing.
