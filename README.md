# Čitaj srpski — v31

Версия для тестирования.

Что изменено в v31:
- убрана старая отдельная база из 20 искусственно подготовленных предложений; тренировка собирает целые предложения непосредственно из текстов сайта;
- после занятия показывается итог: всего заданий, правильные, ошибки, подсказки, пропуски и процент;
- «Показать правильный» теперь учитывается отдельно как «с подсказкой», а «Пропустить» — отдельно; успешный проход по-прежнему засчитывается только при самостоятельной правильной сборке;
- сохранена система 3 успешных проходов с интервалами;
- исправлен баг в тренировке «слово → перевод», из-за которого при правильном ответе коробка могла продвинуться сразу на два шага;
- вся озвучка текста теперь явно использует установленный сербский голос, а не голос браузера по умолчанию;
- уточнены несколько переводов импортированного словаря, в том числе muzlica и muža;
- личные слова и прогресс сохраняются в localStorage и не очищаются обновлением версии.

Важно: браузерная озвучка может правильно выбрать сербский язык, но не гарантирует словарное лексическое ударение. Для следующего этапа качественной озвучки нужен отдельный сербский TTS с поддержкой SSML/фонетических подсказок и словарь ударений.


## v31 — большой этап проверки

- Добавлены 8 расширенных A2-текстов; в каждом есть вопросы и отрицания.
- Словосочетания хранятся отдельно от слов.
- Добавлена отдельная тренировка сохранённых словосочетаний с интервальным закреплением 1/3/7 дней.
- Добавлены локальные переводы распространённых словосочетаний; удалённая проверка используется как резерв.
- Озвучка и следующий этап статистики/адаптивного обучения намеренно не изменялись.

## v37 — лингвистическая проверка и словосочетания
- База сохранена на основе v36: 37 текстов, включая 12 краеведческих текстов Суботицы.
- Исправлены обнаруженные ошибочные глагольные формы и конфликтующие записи, в частности `zaspao`, `odletele`, `naučili`, `odlučili`, `vratio`, а также ряд часто встречающихся форм.
- Расширено покрытие глагольных словоформ из текстов; для неизвестной формы добавлен резервный морфологический запрос к Serbian Word Explorer, если локальная база не смогла определить глагол.
- Сохранено отображение: инфинитив → перевод, прошедшее, настоящее и будущее.
- Исправлен перевод словосочетания `svoju kuću` → «свой дом».
- Старые сохранённые словосочетания автоматически мигрируют на исправленные локальные переводы.
- Убрано условие, при котором отсутствие перевода одного слова автоматически давало «Перевод словосочетания пока недоступен»: теперь для всей фразы пробуются внешние переводчики, затем используется составной резервный перевод.
- При выборе словосочетания конечная точка/запятая/вопросительный знак больше не должны попадать в сохраняемую фразу.
- Исправлена пунктуационная ошибка в заголовке краеведческого текста о Суботицкой синагоге.
- Основной рендер текста, навигация, личные слова, тематические блоки, тренировки и озвучка не переписывались.
