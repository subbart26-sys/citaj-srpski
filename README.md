# Čitaj srpski — v5

Исправлена обработка нажатий на слова: теперь используются обычные обработчики событий JavaScript без inline `onclick`. Это должно корректно работать на GitHub Pages и мобильном Chrome.

Каждое слово текста является отдельной кнопкой, включая короткие слова (`i`, `je`, `u`, `na`, `ga` и т. д.). Любое слово можно открыть и добавить в «Мои слова», даже если перевод пока отсутствует.

Содержимое — учебные адаптации. Перед публикацией большого количества текстов отдельно проверяем права на конкретные источники и переводы.
