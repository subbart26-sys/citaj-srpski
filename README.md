# Čitaj srpski — v12

## Что изменено
- Новые длинные учебные тексты A2: «Učenje u školi», «Šetnja kroz grad», «Dan kulture u gradu», «Izlet u prirodu» — каждый более 100 предложений.
- Реальные исторические тексты Караджича встроены локально в сайт, а не загружаются через iframe/fetch: Međedović, Aždaja i carev sin, Dobra djela ne propadaju.
- Для исторических текстов остаётся ссылка на первоисточник, но сам текст теперь читается внутри Čitaj srpski, с кликабельными словами.
- Навигация «📚 Слова по темам» сделана заметной на мобильном экране; добавлена кнопка на главной.
- Учебная база расширена до 7 блоков по 100 слов: 4 A1/A2 базовых блока + новые блоки «Покупки и одежда» (A1) и «Общение, планы и отношения» (A2).
- Повторение: отдельные блоки, трудные слова, изучаемые слова и интервалы 1 → 2 → 4 → 7 → 14 → 30 дней.
- Ошибка при повторении возвращает слово в первую коробку; правильный ответ переводит его дальше.
- Статистика по коробкам отображается в «Мои слова».
- Импорт/экспорт сохраняет blockId.
- Блок времён глагола показывает сербские формы и перевод инфинитива; поиск блока работает и для инфинитива, прошедшей и настоящей формы, если они есть в VERB_FORMS.
- Дополнен словарь форм для новых учебных текстов и добавлен аккуратный fallback для некоторых падежных форм.
- На мобильном экране навигация перестраивается в сетку 2×2.
- Слова по-прежнему сохраняются в localStorage; обычный commit GitHub не удаляет их.

## Важно про произношение
Сайт использует только найденный голос `sr-*` и не подставляет английский голос. Но браузерный TTS не гарантирует лексическое ударение сербского языка. Для следующего этапа нужен отдельный набор качественных сербских аудиофайлов/голосов.

## Источники исторических текстов
- Vuk Stefanović Karadžić, *Srpske narodne pripovijetke* (1870), Викизворник.
- Тексты указаны в приложении с прямыми ссылками на первоисточники.
