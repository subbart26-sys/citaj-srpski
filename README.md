# Čitaj srpski — v6

Что нового:
- каждое слово в четырёх текстах имеет перевод;
- исправлена работа слов и словаря;
- добавлена первая версия тренажёра интервального повторения;
- 5 коробок: 1 день → 2 дня → 4 дня → 8 дней → 16 дней;
- «Помню» переводит слово дальше, «Не помню» возвращает в первую коробку;
- добавлен экспорт и импорт личного словаря JSON, чтобы сохранить слова при очистке браузера или смене устройства.

Данные по-прежнему хранятся локально в браузере. Регистрация и серверная синхронизация пока не используются.
