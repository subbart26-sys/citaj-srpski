# Čitaj srpski — v10

В этой версии:
- окно перевода закрывается кликом по свободному месту экрана;
- блок глагольных времён показывает сербский инфинитив, прошедшее, настоящее и будущее время + перевод;
- добавлены реальные исторические тексты из Викизворника, которые загружаются непосредственно с источника: Međedović, Aždaja i carev sin, Dobra djela ne propadaju;
- учебные тексты A1/A2 из прошлой версии сохранены;
- озвучка теперь использует только найденный сербский голос (`sr-*`) и не подменяет его английским голосом;
- если сербского голоса на устройстве нет, сайт сообщает об этом вместо неправильного произношения;
- сохранение слов в localStorage, экспорт/импорт и интервальное повторение сохранены;
- короткие тексты не возвращались.

## Важно про произношение
Встроенная озвучка браузера зависит от голосов, установленных на устройстве. Она не даёт гарантии правильного лексического ударения для каждого слова. Поэтому v10 не маскирует отсутствие сербского голоса английским произношением. Для следующего этапа лучше перейти на отдельные сербские аудиофайлы/нейросетевой сербский TTS для слов, где особенно важно ударение.
