- тренировка составления предложений использует только целые предложения из текстов сайта длиной 5–10 слов;

- добавлены «Показать правильный» и «Пропустить»;
- при показе правильного ответа/пропуске предложение помечается как ошибочное и можно сразу перейти дальше;
- остальные функции v24 сохранены.
