# AUDIT v67

## Исправления

1. **Ускорено сохранение одного слова.**
   - `canonicalWord()` больше не выполняет полный перебор всех глагольных словарей для неизвестного существительного.
   - Для уже известных форм используются быстрые O(1)-индексы; неизвестная форма сразу сохраняется, а сетевое уточнение выполняется в фоне.
   - Поиск существующего слова при добавлении больше не вызывает канонизацию для каждого элемента `saved`.
   - Привязка к тексту не запускает дополнительную канонизацию списка.

2. **Улучшена словарная форма.**
   - Добавлена локальная таблица частых падежных форм существительных. В частности: `ulogu → uloga`.
   - Неизвестные формы по-прежнему уточняются в фоне через лемматизатор.

3. **Синхронизация после фоновой лемматизации.**
   - Если сервер позже меняет форму, постоянная связь с исходным текстом переносится на новую лемму, чтобы не оставались две записи (`ulogu` и `uloga`).

## Проверки
- `node --check app.js` — без синтаксических ошибок.
- `index.html` подключает `app.js?v=67`.
- Механизм постоянной привязки слов к тексту из v66 сохранён.

## Ручной тест
- Добавить `ulogu` и проверить, что в общей базе отображается `uloga`.
- Добавить 5–10 слов подряд и оценить задержку каждого сохранения.
- Проверить, что слово сразу появляется в «Слова этого текста».
- После фонового ответа сервера проверить отсутствие дубликата старой и новой формы.
